Buat sebuah website Company Profile modern untuk Koperasi Jasa Karyawan Usaha Sejahtera Bersama (KKUSB) dari NOL sampai siap dijalankan.

PENTING:
- Gunakan Next.js versi terbaru dengan App Router.
- Gunakan TypeScript.
- Gunakan Tailwind CSS.
- Gunakan shadcn/ui sebagai komponen UI utama.
- Gunakan Lucide React untuk icon.
- Gunakan PostgreSQL sebagai database.
- Gunakan Prisma ORM.
- Buat authentication untuk admin.
- Buat Admin Dashboard/CMS sehingga seluruh konten company profile dapat dikelola tanpa mengubah source code.
- Website harus responsive untuk desktop, tablet, dan mobile.
- Jangan membuat sekadar mockup/static HTML. Semua fitur utama harus benar-benar terhubung dan dapat digunakan.
- Struktur project harus rapi, scalable, dan mudah dikembangkan.
- Gunakan clean architecture dan reusable components.
- Gunakan Bahasa Indonesia sebagai bahasa utama.
- Jangan menggunakan WordPress.
- Jangan menggunakan backend terpisah jika tidak diperlukan; gunakan Next.js sebagai full-stack application.

REFERENSI DESAIN:
Gunakan screenshot website KKUSB yang saya berikan sebagai referensi visual dan informasi struktur website, tetapi JANGAN menyalin desain lama secara mentah.

Website baru harus terlihat:
- modern
- profesional
- corporate
- terpercaya
- bersih
- elegan
- responsive
- cocok untuk website resmi koperasi/perusahaan
- memiliki visual yang lebih modern daripada website lama

Gunakan identitas visual KKUSB:
- Dominan hijau

- Hindari desain yang terlalu ramai

- Gunakan subtle animation, jangan berlebihan
